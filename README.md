Κατανεμημένα Συστήματα – Εργαστήριο
===

Το αποθετήριο περιλαμβάνει τον κώδικα και το υλικό των εργαστηρίων του μαθήματος **Κατανεμημένα Συστήματα** του Χαροκοπείου Πανεπιστημίου.

Στο πλαίσιο των εργαστηρίων αναπτύσσεται σταδιακά η διαδικτυακή εφαρμογή **Office Hours**, η οποία επιτρέπει τη διαχείριση ακαδημαϊκών αιτημάτων φοιτητών προς το διδακτικό προσωπικό.

Λήψη:

```shell
git clone https://github.com/gkoulis/DS-Lab-OfficeHours-2627.git
```

---

Εκτέλεση:

```shell
cd DS-Lab-OfficeHours-2627
./mvnw spring-boot:run  # MacOS / Linux
./mvnw.cmd spring-boot:run  # Windows
```

---

Άνοιγμα στον περιηγητή: [localhost:8080](http://localhost:8080/)
